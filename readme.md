# Player Interactive Dating Simulation

## This project aims to take a modern approach to traditional Dating Simulations/Visual Novel-styled games by incorporating additional player elements (i.e., Writing Prompts).

To play the game: Download Python\n
Download the pygame module by typing into PowerShell: pip install pygame-ce\n
To allow the game to access its files: Ctrl + , (Windows) or Cmd + , (Mac), search Execute in File Dir, and check the box
